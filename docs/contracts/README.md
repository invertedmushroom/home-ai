# Contracts

- [Runtime](runtime.md): request receipts, state transitions, artifacts, limits
  and the model-host seam.
- [Observability](observability.md): optional local export, trace correlation,
  metric semantics, privacy and diagnostic failure isolation.
- [Project artifacts](artifacts.md): immutable file snapshots, reviewed proposals,
  stale-base checks, settlement, source/diff/export and preview limits.
- [Workspace presentation](workspace-ui.md): three primary panes, floating tools,
  resource navigation, retained drafts and view/operation lifetimes.
- [Execution](execution.md): manual and model-permitted Node jobs, isolated inputs/resources,
  idempotent receipts, daemon/path ownership, cancellation and recovery.
- [Search in model runs](search.md): default-off native calls, SearXNG transport,
  bounded model loop, durable activity and source links.
- [Public file imports](url-import.md): bounded URL downloads, saved provenance,
  same-run computation inputs and cancellation.
- [Search probe](search-probe.md): standalone keyless and OpenAI hosted checks.
- [Chat image input](vision.md): explicit pixel attachments, model capability,
  frozen provenance and metadata-only later context.
- [Image generation](images.md): fixed-profile WanGP/OpenAI native calls, durable image
  jobs, scoped reconciliation, validated PNG/JPEG storage and result/download UI.
- [Workspace assets](assets.md): uploaded/generated assets, reviewed image
  bindings, metadata-only source context, captured previews and portable ZIP export.
