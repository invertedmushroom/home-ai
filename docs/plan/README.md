# Internal Planning & Deviations

This directory holds active implementation plans, specifications in flight, and the living log of deliberate deviations and review hardening.

Public/implemented technical documentation lives in [`docs/architecture.md`](../architecture.md), [`docs/invariants.md`](../invariants.md), [`docs/contracts/`](../contracts/README.md), and [`docs/adr/`](../adr/README.md).

## Pruning

Plans are scratchpad, not record. When a plan is implemented or abandoned, promote its durable facts to their owning documents per the [fact ownership rules](../README.md#fact-ownership) and delete the plan file. A stale plan surfaces superseded decisions in every repository-wide search. [`deviations.md`](deviations.md) is a living log and stays.
